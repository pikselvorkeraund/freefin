# FinLite

Лёгкий трекер личных финансов (Kotlin + Jetpack Compose + Room + SQLCipher).

- Добавление расходов/доходов крупными кнопками с экранной клавиатурой — любое действие в 2 клика
- Статистика и история по периодам: день, неделя, месяц, квартал, год
- Просмотр, редактирование и удаление операций за выбранный период
- База зашифрована SQLCipher; пароль БД (256 бит) генерируется при первом запуске,
  шифруется AES/GCM-ключом Android Keystore (материал ключа неэкспортируем)
  и пересоздаётся при исчезновении (очистка данных / удаление приложения)
- Сборка split-APK по ABI (armeabi-v7a, arm64-v8a, x86, x86_64), minify + shrinkResources

## Сборка

GitHub Actions собирает 4 APK автоматически при пуше в `main`/`master`
(артефакт `finlite-apks` в разделе Actions).

Локально: `./gradlew :app:assembleRelease`
